## 🌷 داستان بازی چیه؟

همه‌چیز با یک سؤال ساده شروع می‌شه:

**«میای باهام دیت؟»**

اگه جواب «آره» باشه، یه بازی ۲۰ مرحله‌ای شروع می‌شه که توش می‌تونی قرار دلخواهت رو از بین کلی ایده بامزه بسازی؛ از کافه و جنگل گرفته تا بازی‌های دونفره و خوراکی‌های خوشمزه.

اگه هم جواب «نه» باشه، انتخابت محترمه و بازی همون‌جا تموم می‌شه.

## 💝 چطور کسی رو دعوت کنم؟

۱. **سایت بازی** رو باز کن.

۲. اسم خودت و کسی رو که دوست داری دعوت کنی، وارد کن.

۳. ایمیلی رو بنویس که می‌خوای نتیجه دعوت رو دریافت کنه.

۴. روی **«بسازش، بریم برای دعوت! 💘»** بزن.

۵. گزینه **«کپی پیام + لینک دعوت»** رو انتخاب کن یا از دکمه‌های واتساپ و تلگرام کمک بگیر.

۶. پیام رو بفرست؛ حالا نوبت اون شخصه که انتخاب کنه. 💌

> **دریافت نتیجه با ایمیل:** برای اولین استفاده، از بخش ساخت دعوت گزینه «ارسال پیام تست و فعال‌سازی» رو بزن و در صورت دریافت پیام تأیید، ایمیلت رو فعال کن. ارسال نتیجه به فعال‌بودن سرویس ایمیل بستگی داره.

## 💕 اگه دعوت شدم، چی کار کنم؟

۱. لینک اختصاصی رو باز کن و دعوت رو بخون.

۲. بین **«آرههه، بریم! 😍»** و **«نه، ممنون 🙃»** انتخاب کن.

۳. دکمه «نه» برای شوخی تا سه بار جابه‌جا می‌شه؛ در بار چهارم پاسخ منفی ثبت می‌شه. **اگه نمی‌خوای ادامه بدی، می‌تونی همون اول با گزینه رد فوری، بازی رو تموم کنی.**

۴. با انتخاب «آره»، وارد ۲۰ مرحله سؤال جذاب می‌شی. توی هر مرحله انتخاب کن، شانسی جواب بده یا از اون سؤال رد شو.

۵. آخر بازی، خلاصه انتخاب‌هات رو می‌بینی و می‌تونی نتیجه رو کپی یا ارسال کنی.

## 🎲 توی بازی چه چیزهایی منتظرته؟

| دسته | چند تا از انتخاب‌ها |
| :--- | :--- |
| 🌲 کجا بریم؟ | جنگل، کوه، ساحل، کافه یا شهربازی |
| 🍕 چی بخوریم؟ | پیتزا، پاستا، سوشی یا یه غذای متفاوت |
| 🧋 چی بنوشیم؟ | قهوه، ماچا، میلک‌شیک یا هات‌چاکلت |
| 🎡 چه تفریحی کنیم؟ | سینما، بولینگ، اتاق فرار و کلی بازی |
| 💐 چطور خاصش کنیم؟ | گل، هدیه کوچولو، پلی‌لیست و سورپرایز |
| 🌙 حال‌وهوامون چی باشه؟ | رمانتیک، خنده‌دار، آروم یا ماجراجویانه |

**و کلی انتخاب دیگه که بهتره توی خود بازی کشفشون کنی!**

## 📬 آخر بازی چه اتفاقی می‌افته؟

بعد از پایان دعوت یا تکمیل بازی، نتیجه روی صفحه نمایش داده می‌شه. برنامه برای ارسال نتیجه به ایمیل دعوت‌کننده تلاش می‌کنه و امکان کپی یا ارسال دستی هم وجود داره.

## 🤍 چند نکته کوچیک

- این بازی برای سرگرمی و شناخت بیشتر طراحی شده؛ **هر جوابی محترمه.**
- قبل از پاسخ‌دادن مشخصه که نتیجه نهایی برای دعوت‌کننده فرستاده می‌شه.
- لینک دعوت حاوی نام‌ها و ایمیل مقصد به‌شکل کدگذاری‌شده است؛ پس بهتره اون رو عمومی منتشر نکنی.
- فقط می‌خوای امتحانش کنی؟ از **حالت تست دعوت** استفاده کن؛ بدون ارسال ایمیل یا ثبت آمار.
